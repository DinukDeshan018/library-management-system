# Library Management System

A full-stack library system where librarians manage books and members,
and members search books and track their loans.

## Tech Stack
- Backend: Java, Spring Boot, Spring Security (JWT), JPA/Hibernate, MySQL
- Frontend: Angular
- Tools: Docker, GitHub Actions, JUnit 5, Mockito

## Features (Version 1)
- Add, edit, delete and search books
- Member registration and login (ADMIN, MEMBER roles)
- Issue and return books (max 3 books per member)
